# Moteur-de-recherche-sp-cialis-en-AI-et-ML-
Moteur de recherche spécialisé en IA et Machine Learning, développé en Python avec une base de données SQLite. Permet d'indexer et de rechercher dans un corpus multimédia (textes, images, vidéos) via un index inversé, avec prétraitement linguistique (lemmatisation, racinisation, suppression des mots vides) et affichage par pertinence.
